# 📊 Sales Performance & Revenue Growth Dashboard

## 🚀 Overview

This project is an interactive **Power BI dashboard** designed to analyze sales performance, track revenue growth, and monitor key business KPIs for better decision-making.

---

## 🎯 Objective

* Track Revenue, Profit, and Sales Performance
* Compare Target vs Actual Sales
* Identify growth trends and top-performing areas

---

## 🛠️ Tools Used

* Power BI
* Microsoft Excel
* DAX
* Power Query

---

## 📊 Key Features

* KPI Cards (Revenue, Profit, Growth %, Achievement %)
* Revenue by Region
* Monthly Sales Trend
* Sales Channel Analysis
* Interactive Filters (Region, Category, Month, Executive)

---

## 📈 Insights

* Identify top-performing regions and products
* Monitor sales target achievement
* Analyze growth trends over time
